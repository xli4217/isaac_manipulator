# RT-DETR [](https://nvidia-isaac-ros.github.io/concepts/object_detection/rtdetr/index.html\#rt-detr "Link to this heading")

[RT-DETR](https://github.com/lyuwenyu/RT-DETR) (Real-Time Detection Transformer)
is a popular object detection model that excels in both detection quality and speed.

Inspired by RT-DETR, NVIDIA has also developed a new category of
[SyntheticaDETR](https://catalog.ngc.nvidia.com/orgs/nvidia/teams/isaac/models/synthetica_detr)
models that are trained exclusively on synthetically generated data
rendered with Omniverse technology.
