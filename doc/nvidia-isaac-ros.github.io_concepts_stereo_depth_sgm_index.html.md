# SGM [](https://nvidia-isaac-ros.github.io/concepts/stereo_depth/sgm/index.html\#sgm "Link to this heading")

[SGM](https://en.wikipedia.org/wiki/Semi-global_matching) (Semi-Global Matching) is a stereo matching algorithm used in computer vision to compute depth maps from stereo image pairs.
