# DetectNet [](https://nvidia-isaac-ros.github.io/concepts/object_detection/detectnet/index.html\#detectnet "Link to this heading")

[DetectNetV2](https://docs.nvidia.com/tao/archive/5.3.0/text/object_detection/detectnet_v2.html) is an NVIDIA-developed object-detection model that is included in the [TAO Toolkit](https://developer.nvidia.com/tao-toolkit).
To learn more about using DetectNet with TAO, see [here](https://catalog.ngc.nvidia.com/orgs/nvidia/teams/tao/models/pretrained_detectnet_v2).
